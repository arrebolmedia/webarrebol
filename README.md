# Arrebol Theme

Este es un tema personalizado de WordPress diseñado para sitios de fotografía y video.

## Instalación
1. Copia la carpeta `arrebol-theme` en el directorio `wp-content/themes` de tu instalación de WordPress.
2. Activa el tema desde el panel de administración de WordPress.

## Personalización
- Edita los archivos de plantilla (`front-page.php`, `page-galeria.php`, `page-contacto.php`) para ajustar el contenido.
- Modifica `style.css` para cambiar los estilos visuales.

## Características
- Diseño moderno.
- Soporte para imágenes destacadas.
- Plantillas personalizadas para página principal, galería y contacto.

## Créditos
Creado con ❤️ para sitios de fotografía y video.
